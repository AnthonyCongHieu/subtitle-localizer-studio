# Subtitle Localizer Studio

Windows-first, local-first tooling for extracting hard subtitles from video, reconstructing SRT timing, optional localization to Vietnamese, review/editing, masking, and export.

Implementation is ticket-gated. The current branch contains T00 foundation and benchmark evidence only; production OCR/API/UI work starts in later tickets.
